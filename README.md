# Crimson Eclipse

A blood moon mod for [Horizon](https://playhorizon.dev) (Minecraft Java 26.3 rewritten in Rust).

Some nights the moon rises red. The sky cracks around it, blood meteors fall and plant crimson crystals that spread over the land, red lightning strikes, rifts tear the air and something watches from the moon. At dawn the sun burns it all back.
