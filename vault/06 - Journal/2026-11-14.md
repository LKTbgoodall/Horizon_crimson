## 🧠 Learned / found
- Render API read at `9f42064` (`native_render.rs`, its `generated.rs`, wgpu 30.0.1): `Hooks::render(&self) -> Option<&dyn RenderHooks>`; `RenderHooks { world_drawn, render_needs, hand_drawn, world_warp }`, no host in any of them; `WorldDrawn.view_proj` is a glam `Mat4` (`.inverse().to_cols_array()` needs no glam import); wgpu comes from `horizon_client::mod_api::wgpu`. The vanilla moon is a quad of half-size 20 at distance 100 along `(-sin a, cos a, 0)` with `a = sky.moon_angle` (`frame_geometry.rs`), its phase `(day_time / 24000) % 8`.
- API read at `9f42064` for the glue (generated `mod_api_generated*.rs`): `Host::level(dim) -> Option<LevelRef>` (server only, `Copy`), `level_day_time`, `level_set_day_time(level, time) -> bool`, client `Host::day_time()`; `register_commands` takes `NativeCommand::op("crimson start", 2)`, `perform_command` gets `event.command` without the slash and answers with `host.feedback(Text)`; `ComputeFogColorEvent { partial, camera, fog_type: horizon_client::fog::FogType, rgb: &mut [f32; 3] }`; `CameraShakeEvent { partial, shake: &mut NativeShake { pitch, yaw, roll, offset } }`.
- Read at the pin `9f42064` (Cagebound's `ext/src-9f42064`; this repo has no `ext/` yet): `native-hooks.json` has **no moon, sky or star hook** (only `compute_fog_color`, `render_fog`, `day_time`, `weather`). The sky must be painted by our `world_drawn` pass where depth is 0. `world_warp` also accepts a `world_fragment` (after a `// [fragments]` line) that paints every terrain pixel. → [[Horizon hooks and API]] § A8, [[Open questions]] #6.
