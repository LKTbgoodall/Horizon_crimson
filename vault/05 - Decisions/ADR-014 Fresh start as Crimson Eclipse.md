# ADR-014: Fresh start as Crimson Eclipse

## Context
- Bastien dropped Cagebound after seeing it in game and asked for a mod built around spectacular effects like the TikTok Horizon mods. Of the ideas proposed he loved cataclysms and crystal corruption, then chose a **blood moon** during which many such events happen.
- He chose a new folder (Cagebound stays, paused).

## Decision
- New folder `D:\dev\mod_minecraft\crimson-eclipse`, mod id `crimson_eclipse`, name **Crimson Eclipse** (Claude's pick; proposed until Bastien confirms).
- Reuse: the Horizon notes, the process ADRs (001 to 004, 012, 013, numbers kept), the tools, Cagebound's lessons and its GPU effects draft.
- The blood moon is the trigger and the stage; events are modules the scheduler picks.

## Consequences
- No code yet; renaming is free until phase 1.
